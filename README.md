# Manahil AI Assistant

Voice-controlled AI assistant.

## Features
- Wake word: "Manahil"
- Responds: "Yes boss."
- Opens apps (Notepad, Chrome)
- Opens websites (YouTube, Google)
- System volume control
- AI responses via OpenAI API

## Run
1. Install requirements:
   pip install -r requirements.txt
2. Run:
   python main.py
